### Endpoints Available

   Method       | Endpoint      | Description
  --------------|---------------|-------------------------------------------------------------------------------------------
   GET          | /api/flyovers | Returns all detected flyovers (newest first). Supports ?limit=N (e.g. ?limit=10).
   GET          | /api/status   | Returns the current tracker state, poll interval, whether it is active, and total logged.
   GET          | /api/live     | Returns the current aircraft currently inside your bounding box from the last poll.
   POST         | /api/config   | Update configuration dynamically (turn on/off, adjust poll interval).
  ──────
  ### Quick Test Commands

  #### 1. Fetch recent flyovers

  You can open this directly in your browser or run:

    curl -s "http://localhost:8080/api/flyovers?limit=5"
  #### 2. Check server status

    curl -s http://localhost:8080/api/status

  #### 3. Pause tracking (protect OpenSky credits)

  When you aren't using it, send running: false. The background thread stops polling OpenSky immediately:

    curl -s -X POST http://localhost:8080/api/config \
      -H "Content-Type: application/json" \
      -d '{"running": false}'

  #### 4. Resume tracking & adjust interval
    curl -s -X POST http://localhost:8080/api/config \
      -H "Content-Type: application/json" \
      -d '{"running": true, "poll_interval_sec": 30}'
  ──────
  ### How to Run It in the Future
  Whenever you want to start the server yourself:

    python3 server.py

  (By default it binds to port 8080 or reads the $PORT environment variable if deployed to a cloud host).
  
  
  
   ### 1. Run the Command

  Make sure you are in the project folder (/home/mike/apps/flights) and run:

  • In your browser: Open http://localhost:8080/api/flyovers

    curl -s "http://localhost:8080/api/flyovers?limit=5"

  ### 3. Stop the Server

  To stop the server at any time, press Ctrl + C in that terminal window. It will shut down the tracker thread and free port
  8080 cleanly.
